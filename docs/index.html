//racehud

A minimal, configurable overlay for iRacing that looks like your code editor.

Download for Windows View source

free & open source (MIT) · Windows 10/11 · iRacing in borderless windowed mode

// click-through

A transparent, always-on-top window. It never steals focus or mouse input from the sim.

// 60 Hz

Reads iRacing's official telemetry 60 times a second. Gaps, deltas and the radar keep up with the car.

// configurable

Move, resize and toggle every widget, set its opacity, and recolour every data type live.

// color-blind safe

One-click palettes for red/green and blue/yellow colour blindness cover every good/bad colour.

// tray app

Installer, desktop shortcut, start with Windows and a tray icon. No console windows.

// minimal

Dark, quiet, Fira Code. Widgets hide themselves when they have nothing to say.

// widgets

Every widget, one job

// relative

The cars nearest to you on track, any class, with gaps timed the same way as iRacing's own relative.

  • race position, ranked live by track position, not only at timing lines
  • car number, iRating as 1.2k, country flag, class tag
  • lapped and lapping cars tagged +1L / -1L and coloured
  • radio icon while a driver is talking; rows slide when the order changes
  • in practice and qualifying it becomes standings: every car with a time by best lap, including cars in the pits or disconnected

// session

Session type as the title (practice, qualify, race), current lap of the total, position and time left.

  • timed races estimate the total laps from the leader's pace (shown as ~28), not before the green
  • position turns green or red with places gained or lost since the start
  • track name and layout at the bottom

// Δ delta

Live delta to your session best (or best, optimal, last lap: your pick). Colour shows the sign; brightness shows the trend, bright while it grows and faded while it shrinks.

// ▲ ahead · ▼ behind

The car right in front of and behind you on track, with the gap in seconds and a bar that fills as it gets closer.

  • full colour while you're gaining, washed out while you're losing
  • status line: catching in 3 laps, on your tail, holding
  • hides beyond a gap you choose (default 10 s)

// laps

Your last lap (green when it's your best) and your optimal lap: the sum of your best time in each of the track's sectors over clean laps.

// fuel

Tank level with a marker for what you need to reach the flag, average use per lap, laps left in the tank and how much more you need to finish.

// incidents

Your incident count against the session limit, going from gray to red as it grows. When an incident happens, a short alert names it in the middle of the screen: off-track 1x, loss of control 2x, contact 4x.

// map

The real shape of the track, painted every 10 m green or red by time gained or lost against your last lap.

  • car dots, with you and the cars ahead/behind highlighted
  • follow mode: centred on you and rotated heading-up

// radar

Cars around you to scale, with a red glow on the side where someone is alongside. It flashes when you're three wide.

  • appears only when a car is close: 2 m ahead or 3 m behind by default, adjustable
  • hidden in qualifying

// time

Wall clock, so you know when dinner is.

// edit mode · Ctrl+Shift+O

Configure everything, live

Press Ctrl+Shift+O (or use the tray icon) to edit the overlay on top of the sim:

  • drag to move, mouse wheel to resize, an on/off switch on every widget
  • per-widget size, background and opacity, radar range, map follow mode, gap limits
  • a colour picker for every data type, plus colour-blind palettes
  • everything is saved automatically

// install.md

Install

  1. Download racehud-setup.exe (or pick a version on the releases page) and run it. It installs for your user; no admin needed.
  2. If Windows SmartScreen warns about an unknown publisher, choose More info → Run anyway. The installer isn't code-signed.
  3. In iRacing, set Options → Graphics to borderless windowed. In exclusive fullscreen, overlays are hidden.
  4. Join a session. The HUD shows up on its own, and lives in the tray.

// faq.md

FAQ

Is racehud free?

Yes. It's free and open source under the MIT license. The code is on GitHub; issues and pull requests are welcome.

Is it allowed in iRacing?

racehud only reads iRacing's official telemetry API, the same one every overlay uses. It never writes to the sim or touches its files.

Does it work in fullscreen?

Use borderless windowed mode. Windows can't draw overlays over exclusive fullscreen games.

Where are my settings?

Layout and colours are saved automatically. Settings, recorded track maps and the log are in %APPDATA%\racehud\data (tray → Open settings folder).

Does racehud collect any data?

No. It reads iRacing's telemetry on your PC and keeps everything there. The overlay only downloads the Fira Code font from Google Fonts and country flag images from flagcdn.com; those requests carry nothing about you or your sessions.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Installers are built from the GitHub repository by GitHub Actions and signed only after an approver confirms the request. Committers, reviewers and approvers: Anton Rusinov.

Where does the track map come from?

iRacing doesn't provide track shapes, so racehud draws each track once, from your driving, and saves it. On a track you've never driven, the map shows a placeholder circle until your first clean lap; after that it's there from the moment you load in.
