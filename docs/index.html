//HUDsplay

A minimal, configurable overlay for iRacing that looks like your code editor.

Download for Windows View source

free & open source (MIT) · Windows 10/11 · iRacing in borderless windowed mode

// click-through

A transparent, always-on-top window. It never steals focus or mouse input from the sim, and fades out in replays and when you alt-tab away.

// 60 Hz

Reads iRacing's official telemetry 60 times a second. Gaps, deltas and the radar keep up with the car.

// configurable

Move, resize and toggle every widget, set its opacity, and recolor every data type live.

// themes

Dark+, One Dark Pro, Dracula, Monokai, GitHub Dark, Night Owl, Tokyo Night, Solarized Dark. Your tweaks are saved per theme.

// color-blind safe

One-click palettes for red/green and blue/yellow color blindness cover every gain/loss color.

// tray app

Installer, start with Windows and a tray icon. No console windows.

// widgets

Every widget, one job

// relative

The cars nearest to you on track, any class, with gaps timed the same way as iRacing's own relative.

  • three cars each side, plus the leader pinned on top
  • position badge in the class color, iRating on a badge in the driver's license color, brighter with higher safety rating
  • lapped and lapping cars tagged +1L / -1L; radio icon while a driver is talking
  • before the green it shows the grid; in practice and qualifying it becomes standings by best lap

// Δ delta

Live delta to your session best (or best, optimal, last lap: your pick). The bar's side shows ahead or behind; its color shows what's happening right now: green while you gain time, red while you lose it, bone white when steady.

// ▲ ahead · ▼ behind

The car right in front of and behind you on track, with the gap in seconds and a bar that fills as it gets closer.

  • full color while you're gaining, washed out while you're losing
  • status line in spotter words: closing 0.3 s/lap, pulling away 0.2 s/lap, on your tail, holding
  • hides beyond a gap you choose (default 10 s)

// radar

Cars around you to scale, with a red glow on the side where someone is alongside. It flashes when you're three wide.

  • appears only when a car is close: 2 m ahead or 3 m behind by default, adjustable
  • hidden in qualifying

// map

The real shape of the track, painted every 10 m like the delta bar: green where you gained time against your last lap, red where you lost it, brighter the faster it went.

  • car dots in their class color, a red or blue ring on cars a lap up or down
  • follow mode: centred on you and rotated heading-up
  • drawn from your own driving on the first clean lap; shipped maps for tracks others have driven

// session

Session type as the title (practice, qualify, race), current lap of the total, position and time left.

  • timed races estimate the total laps from the leader's pace (shown as ~24)
  • position turns green or red with places gained or lost since the start

// fuel · laps

Tank level with a marker for what you need to reach the flag, use per lap, laps left in the tank and how much more you need to finish.

Your last lap (green when it's your best) and your optimal lap: your best time in each sector over clean laps, summed.

// incidents

Your incident count, the next penalty warning and the DQ limit, like iRacing shows them: 1x / 17x / 25x. When an incident happens, a short alert names it: off-track 1x, loss of control 2x, contact 4x.

// time

Wall clock, so you know when dinner is.

// edit mode · Ctrl+Shift+O

Configure everything, live

Press Ctrl+Shift+O (or use the tray icon) to edit the overlay on top of the sim:

  • drag to move (widgets snap to each other and to the screen's center lines), mouse wheel to resize, an on/off switch on every widget
  • per-widget size, background and opacity, radar range, map follow mode, gap limits
  • a color theme, a color picker for every data type and color-blind palettes; your colors are kept per theme
  • everything is saved automatically

The panel on the right is the real one: pick a theme or change a color and this page follows.

// install.md

Install

  1. Download hudsplay-setup.exe (or pick a version on the releases page) and run it. It installs for your user; no admin needed.
  2. If Windows SmartScreen warns about an unknown publisher, choose More info → Run anyway. The installer isn't code-signed.
  3. In iRacing, set Options → Graphics to borderless windowed. In exclusive fullscreen, overlays are hidden.
  4. Join a session. The HUD shows up on its own, and lives in the tray.

// faq.md

FAQ

Is HUDsplay free?

Yes. It's free and open source under the MIT license. The code is on GitHub; issues and pull requests are welcome.

Is it allowed in iRacing?

HUDsplay only reads iRacing's official telemetry API, the same one every overlay uses. It never writes to the sim or touches its files.

Does it work in fullscreen?

Use borderless windowed mode. Windows can't draw overlays over exclusive fullscreen games.

Where are my settings?

Layout and colors are saved automatically. Settings, recorded track maps and the log are in %APPDATA%\HUDsplay\data (tray → Open settings folder).

Does HUDsplay collect any data?

No. It reads iRacing's telemetry on your PC and keeps everything there. The overlay only downloads the Fira Code font from Google Fonts and country flag images from flagcdn.com; those requests carry nothing about you or your sessions.

Where does the track map come from?

iRacing doesn't provide track shapes, so HUDsplay draws each track from your driving on a clean lap and saves it, or uses a map shipped with the app. It quietly re-checks the map on your first laps, so a changed track gets updated. If a map looks wrong, the tray menu re-records it or reports it, and "Share my track maps" turns maps you recorded into a pull request for everyone.
